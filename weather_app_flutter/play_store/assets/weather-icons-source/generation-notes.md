# WeatherApp original weather icons

Created on 28 July 2026 specifically for WeatherApp using OpenAI image generation.
The approved concept contains sixteen original day and night weather conditions:
clear, partly cloudy, overcast, fog, drizzle, rain, snow and thunderstorm.

The production sheet was generated on a chroma-key background, converted to
transparency, divided into equal cells and exported as 512 x 512 PNG assets.

Final mapping: `113` clear, `116` partly cloudy, `122` overcast, `248` fog,
`266` drizzle, `302` rain, `338` snow and `389` thunderstorm. The same mapping
is used for day and night variants.
